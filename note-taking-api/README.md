# Note-Taking REST API

A lightweight RESTful API built with Node.js and Express.js to manage personal notes using full CRUD operations.

## Features

- **Create**: Add new notes with a title and content.
- **Read**: Fetch and view all notes in JSON format.
- **Update**: Edit existing notes by ID.
- **Delete**: Remove notes by ID.

## Tech Stack

- **Runtime**: Node.js
- **Framework**: Express.js
- **Version Control**: Git & GitHub
