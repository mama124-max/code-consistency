# Full-Stack Note-Taking Application

A responsive, full-stack web application that allows users to seamlessly create, read, update, and delete notes in real-time. Built with modern web technologies and deployed live on the cloud.

## Features

* **Live Public Access**: Hosted globally so anyone can access and manage notes from anywhere.
* **CRUD Operations**: Complete Create, Read, Update, and Delete functionality synchronized with a cloud database.
* **Persistent Storage**: Utilizes MongoDB Atlas to ensure notes remain securely stored.

## Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript, hosted via GitHub Pages.
* **Backend**: Node.js, Express.js, hosted on Render.
* **Database**: MongoDB Atlas with Mongoose ODM.
